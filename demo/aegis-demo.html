Read this before you believe it

    
    
      
  • It is a small demo shop on one machine, not a production site. The app is BookNook, a deliberately simple target in this repository.
    • 
      
  • The gate's watching windows are shortened to 8 s and 12 s so the demo fits in a minute. The defaults are 30 s and 45 s. Every stage still runs, but a rule is watched for less time before it enforces.
    • 
      
  • This is one recording of one run, and the attack was chosen because the standard rules miss it. AEGIS did not cause the 2 cracked accounts, but it did not prevent them either: the first 94 guesses got through.
    • 
      
  • The testing behind these claims, and the places where AEGIS still falls short (slow attacks, a load balancer that hides client addresses, a gateway that stops), are in the security review and the re-measurement.
    • 
    

  


  

    
Run it yourself

    
Needs Python 3.10 or newer and the gateway built once (install). No accounts, no paid services.

    
python demo/run_demo.py

    
To record your own: python demo/record.py demo/aegis-demo.cast -- python demo/run_demo.py, then python demo/build_page.py demo/aegis-demo.cast demo/aegis-demo.html --standalone.
